# 日计

菜单栏里的每日计时。点开，输入正在做的事，回车开始。可以同时记几件事。停下之后，把起止时间写成 Markdown，放进你选的文件夹，方便以后用 Obsidian 或 AI 回看。

需要 macOS 14 或更新版本。

## 下载

到 [Releases](../../releases) 下载 `Riji-x.y.z.dmg`。打开磁盘映像，把「日计」拖进「应用程序」。

这是本地签名，没有经过 Apple 公证。第一次打开如果被拦截：在「应用程序」里对「日计」按住 Control 再点「打开」。图标在屏幕最上方菜单栏，不在程序坞。

点菜单栏里的「日记 · 文件夹名」，选择要写入记录的目录。没有选过时，会用「文稿/每日小记」；如果家里已经有「文稿/Sankai-Vault/每日小记」，就沿用那个。

## 从源码运行

```bash
./run.sh
```

会编译、打包并打开。做安装包：

```bash
bash scripts/make-dmg.sh
```

产物在 `dist/Riji-<版本>.dmg`。
